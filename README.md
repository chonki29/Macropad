# Custom Macropad

A custom 5-key macropad built around the Seeed XIAO RP2040.

## Features

- 5× Cherry MX-style switches
- EC11 rotary encoder for volume
- 0.91" 128×32 OLED
- Custom PCB
- Custom 3D-printed case
- QMK firmware
- USB-C
